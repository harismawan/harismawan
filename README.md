## Achmad Fauzi Harismawan

Jakarta · DevOps Team Lead at [BNI](https://github.com/bni-api), on the wondr digital banking platform. CI/CD, release automation, and the Kubernetes underneath it.

### Infrastructure and delivery

- **[homelab-ops-console](https://github.com/harismawan/homelab-ops-console)** — one screen for a homelab spread across MicroK8s, Argo CD, Elastic, and Postgres. Rust, strictly read-only.
- **[mock-json](https://github.com/harismawan/mock-json)** — a mock JSON API that hot-reloads from a ConfigMap. Same container locally, on OpenShift, or on plain Kubernetes.

### Agents and AI tooling

- **[omnigateway](https://github.com/harismawan/omnigateway)** — your AI subscriptions, behind an OpenAI-shaped API. Point an existing client at it; nothing else changes.
- **[claude-utilization](https://github.com/harismawan/claude-utilization)** — a self-hosted dashboard for where your Claude Code tokens actually go.
- **[omnigateway-plugin-pokemon](https://github.com/harismawan/omnigateway-plugin-pokemon)** — every API key raises a Pokémon that grows on the tokens it spends.

### Libraries

- **[stamp-ui](https://github.com/harismawan/stamp-ui)** — React components that look stamped, not rendered. Chunky borders, hard shadows, no gradients, and the palette stays yours. [Live gallery](https://stamp-ui.harismawan.com).
- **[mycelium](https://github.com/harismawan/mycelium)** — notes that stay plain markdown, linked like a graph. Built to be read by humans and agents.
- **[node-encrypted](https://github.com/harismawan/node-encrypted)** — encrypt and decrypt a string in Node without reading the crypto docs again.
