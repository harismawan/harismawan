## Achmad Fauzi Harismawan

Android, iOS, and fullstack developer. Currently at [@bni-api](https://github.com/bni-api).

### What I'm building

**[stamp-ui](https://github.com/harismawan/stamp-ui)** — a React component library in the "stamp" aesthetic: chunky 2px borders, hard offset shadows, flat fills, no gradients. Brand-agnostic, so the palette stays yours. TypeScript and styled-components, published as `@harismawan/stamp-ui`, with a [live gallery](https://stamp-ui.harismawan.com).

**[omnigateway](https://github.com/harismawan/omnigateway)** — a self-hosted gateway that speaks the Anthropic and OpenAI APIs and answers them using AI subscriptions you already pay for. Point an existing client at it and nothing else has to change.

**[mycelium](https://github.com/harismawan/mycelium)** — a markdown-first knowledge base with wikilinks, backlinks, and a knowledge graph, built to be read by humans and AI agents alike. The notes stay plain markdown on disk.

**[homelab-ops-console](https://github.com/harismawan/homelab-ops-console)** — a read-only operations console for my homelab, written in Rust. A correlation layer over MicroK8s, Argo CD, Elastic, and Postgres rather than another Grafana.

### Before that

Mobile work going back to 2014: a sign language app in Kotlin, a trading automation client for Binary.com, WebRTC experiments on Android, and the Google Associate Android Developer track.
